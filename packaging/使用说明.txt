AutoCheck · 圆通国际批量查询（Windows 64 位）

一、安装版
双击 AutoCheck-1.0.0.exe，按安装向导完成后，从桌面或开始菜单启动 AutoCheck。
安装包已经包含 Java 运行环境和查询浏览器，无需安装 Java、Maven、Chrome 或 Edge。
按当前用户安装，一般不需要管理员权限。

二、免安装版
将 AutoCheck-1.0.0-Windows-x64-Portable.zip 完整解压到任意可读位置，再双击其中的 AutoCheck/AutoCheck.exe。
请勿只复制 AutoCheck.exe，也不要直接在 ZIP 内运行。整个目录中的 runtime 和 app 都需要保留。

三、使用方法
1. 粘贴单号，或导入 TXT / CSV / Excel。每批自动查询最多 10 个单号。
2. Excel 读取首个工作表 A 列；建议单号存为文本。支持重复单号去重。
3. 在“筛选条件与设置”中配置地点、物流信息和匹配方式，点击“保存并应用”。
4. 点击“开始全部查询”，程序会打开随软件附带的查询浏览器。
5. 遇到验证码时手动填写；如要求在网页验证，请在该浏览器中完成，然后点击继续。
6. 中断后使用“继续未完成 / 失败项”；“开始全部查询”会刷新全部当前单号。
7. 可导出当前筛选结果 CSV，或完整轨迹 JSON。

四、数据保存
安装版和免安装版都将查询进度、设置和浏览器会话保存在：
%LOCALAPPDATA%\AutoCheck
可将以上路径粘贴到资源管理器地址栏打开。
更新或卸载软件后保留该目录，以便保留历史进度。若要复制查询进度到另一台电脑，可复制 progress.json 和 settings.json；浏览器验证需要在新电脑重新完成。
发布包不包含开发电脑的查询数据、配置或浏览器 Cookie。

五、适用范围
面向 Windows 10/11 的 Intel / AMD 64 位电脑，需要能够联网访问圆通官网。
这是 Windows 程序，不能直接用于 macOS、Linux、32 位 Windows 或手机；不承诺兼容 Windows 7/8。
已包含运行依赖，离线时可以安装、打开和查看已有结果；实时查询仍需要网络。
验证码需要人工处理。

本程序安装包未配置商业代码签名证书，发布者可能显示为“未知发布者”。
