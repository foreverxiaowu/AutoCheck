AutoCheck · 圆通国际 / 17TRACK / 顺丰国际批量查询（Windows 64 位）

一、安装版
双击 AutoCheck-1.1.2.exe，按安装向导完成后，从桌面或开始菜单启动 AutoCheck。
安装包已经包含 Java 运行环境和查询浏览器，无需安装 Java、Maven、Chrome 或 Edge。
安装版改为供所有用户使用，安装和卸载时需要管理员授权，默认位于 Program Files 下的 AutoCheckApp。
从 1.1.0 升级时，请先在原安装用户下卸载旧版；按用户安装的旧版不能保证自动迁移为所有用户安装。
没有管理员权限时请使用免安装版。

二、免安装版
将 AutoCheck-1.1.2-Windows-x64-Portable.zip 完整解压到任意可读位置，再双击其中的 AutoCheck/AutoCheck.exe。
请勿只复制 AutoCheck.exe，也不要直接在 ZIP 内运行。整个目录中的 runtime 和 app 都需要保留。

三、使用方法
1. 顶部选择查询平台，再粘贴单号，或导入 TXT / CSV / Excel。圆通每批 10 单，17TRACK 每批 40 单，顺丰国际每批 20 单。
2. Excel 读取首个工作表 A 列；建议单号存为文本。自动去重，兼容不间断空格等 Unicode 空白。
3. 各平台的“筛选条件与设置”单独保存，编辑后点击“保存并应用”。只匹配最新一条轨迹，历史记录不参与当前进度筛选。
4. 点击“开始全部查询”，程序会打开随软件附带的查询浏览器。
5. 遇到验证码时手动填写；如要求在网页验证，请在该浏览器中完成，然后点击继续。
6. 中断后使用“继续未完成 / 失败项”；“开始全部查询”会刷新全部当前单号。
7. 可导出当前筛选结果 CSV，或完整轨迹 JSON。
8. 17TRACK 内置中通国际（190175）、中国邮政（3011）、递四方（190094），默认选择中通国际；“物流公司配置”可添加公司名称与 fc 编码，不同公司的进度分开保存。旧配置会一次性补入缺少的中国邮政和递四方，保留自定义公司及当前选择，之后仍可自行删改。
9. 17TRACK 和顺丰只显示物流进度，不单独判断或显示最新位置地区。17TRACK 默认条件为“清关持续中”“快件已开始清关”“成都青龙场”；顺丰默认条件为“清关进行中”“海关查验”，均可修改。
10. 顺丰如需验证码或手机号校验，请在打开的官网窗口手动完成并查询，再回程序继续。不要复用旧验证码票据。
11. 关闭窗口时，若有查询在进行，会先等待当前请求并保存返回的结果、关闭查询浏览器，再退出整个程序。不要连续重复启动。

四、数据保存
安装版和免安装版都将查询进度、设置和浏览器会话保存在：
%LOCALAPPDATA%\AutoCheck
可将以上路径粘贴到资源管理器地址栏打开。
更新或卸载软件后保留该目录，以便保留历史进度。若要复制查询进度到另一台电脑，可复制 progress.json 和 settings.json；浏览器验证需要在新电脑重新完成。
圆通数据保存在目录根部；17TRACK 数据位于 17track 子目录，顺丰数据位于 sf 子目录，跨电脑迁移时复制相应目录。
发布包不包含开发电脑的查询数据、配置或浏览器 Cookie。

五、适用范围
面向 Windows 10/11 的 Intel / AMD 64 位电脑，需要能够联网访问所选查询平台的官网。
这是 Windows 程序，不能直接用于 macOS、Linux、32 位 Windows 或手机；不承诺兼容 Windows 7/8。
已包含运行依赖，离线时可以安装、打开和查看已有结果；实时查询仍需要网络。
验证码需要人工处理。

本程序安装包未配置商业代码签名证书，发布者可能显示为“未知发布者”。
